# Topology and geometric topology.

# A pack rather than shipped vocabulary: it is excellent if you work on this
# and clutter if you do not, and the same is true of every specialism.  Import
# it with `python3 scripts/import_pack.py topology`.

# Names are written with their capitals, so `rdmstr` gives Reidemeister.  The
# lowercase adjectives derived from them are separate entries, because
# `noetherian` and `abelian` really are written in lower case.
