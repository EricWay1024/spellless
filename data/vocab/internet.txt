# The internet as it is actually used, and the decade the corpus missed.
#
# The base list is Google Books intersected with SCOWL: it is excellent English
# and it stops somewhere around 2008.  It has never seen ChatGPT, Instagram,
# TikTok, COVID, a hashtag or a selfie, and it has `youtube` and `facebook`
# only as stray lowercase tokens.  Everything here is a word people type into
# ordinary prose several times a day.
#
# Everything here has a lowercase reading worth keeping.  `Anthropic` is
# offered beside `anthropic`, which is a real adjective; `Copilot` beside the
# co-pilot, `Android` beside the robot, `Signal` beside the signal, `Google`
# beside the verb.  Names that are not English words at all -- ChatGPT, TikTok,
# YouTube, COVID -- are in brands.txt, which declares that once.
#
# Two-letter entries are deliberately absent, for the reason technology.txt
# gives: at that length an entry is a rival for half the short input there is.
# `DM` is the one that hurts to leave out.
