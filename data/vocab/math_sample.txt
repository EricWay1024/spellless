# Supplemental vocabulary for Spellless: pure mathematics and its working
# language.
#
# This file exists to demonstrate the mechanism -- none of these words are
# referenced by the matching or ranking code.  Delete it, edit it, or drop
# extra *.txt files next to it and re-run scripts/build_dictionary.py.
#
# Format, one entry per line:
#     word                 use the default supplemental frequency
#     word <TAB> 1234567   use an explicit corpus frequency
# Lines starting with '#' and blank lines are ignored.
#
# An entry written WITH CAPITALS is indexed under its lowercase form and
# remembers the capitals, so "grthndck" gives back "Grothendieck".  Only write
# capitals where the lowercase spelling would be wrong: "Noether" yes,
# "manifold" no.
#
# Words already present in the base frequency list keep the larger of the two
# frequencies, so listing a common word here can only promote it.
