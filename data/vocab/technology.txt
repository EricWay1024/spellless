#!rank 30000
# Words the computer put into English after the corpus stopped reading.
#
# `frequency_dictionary_en_82_765.txt` is built from Google Books and knows
# `docker`, `python` and `linux` -- which have other lives -- while having
# never heard of `macOS`, `JSON`, `kubectl` or `numpy`. That is not a gap in
# English; it is a gap between when the books were written and when these were
# named.
#
# The bar is the one in proper_nouns.txt, applied twice over, because an
# acronym is a much more dangerous entry than a place name.
#
#   1. **The lowercase spelling must not already be a word.** Adding `RAM`
#      gives the key `ram` a written form, so typing `ram` commits `RAM` --
#      everywhere, including when you meant the animal. The same objection
#      retires `REST`, `POP`, `CD`, `ARM`, `SIM`, `CAD`, `RAID`, `WAN`, `MOD`
#      and `ROM`, and on the same grounds `Bash`, `React`, `Notion`, `Fedora`
#      (a hat), `Nice`, `Rest` and `Trinity`. Every one of those is still
#      typeable; it simply keeps the spelling English gave it.
#
#   2. **It has to be something you would type in prose.** Not every acronym in
#      a standards document belongs in a dictionary that has to rank `API`
#      against every four-letter word.
#
# Ranked at 30,000 -- below ordinary prose, above the tail -- because these are
# common in one kind of writing and absent from every other.
